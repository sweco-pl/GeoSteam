# GeoSteam

**GeoSteam** to aplikacja do automatycznej aktualizacji otwartych danych zawartych w ewidencji zbiorów i usług danych przestrzennych (zgodnie z infrastrukturą informacji przestrzennej, IIP/INSPIRE).

## Opis projektu

Celem projektu jest ułatwienie i zautomatyzowanie procesu aktualizacji metadanych oraz informacji o zbiorach i usługach danych przestrzennych publikowanych w ramach krajowej ewidencji. Projekt jest rozwijany jako open source, aby wspierać instytucje publiczne i inne podmioty zobowiązane do prowadzenia oraz aktualizacji takiej ewidencji.

## Status projektu

🚧 Projekt jest we wczesnej fazie rozwoju. Struktura, funkcjonalności i dokumentacja będą sukcesywnie uzupełniane.

## Wymagania

- Python 3.11+

## Instalacja

```bash
git clone https://github.com/sweco-pl/GeoSteam.git
cd GeoSteam
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
